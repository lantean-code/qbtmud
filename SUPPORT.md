# Support

## Getting Help

Use GitHub Discussions for support and community conversation.

- **Q&A**: help with setup, configuration, routing, reverse proxies, browser behaviour, or usage questions
- **General**: broad discussion that does not fit another category
- **Ideas**: early-stage suggestions that are not ready to become roadmap issues
- **Show and tell**: screenshots, themes, deployment examples, or other community showcases

Use GitHub Issues when you have an actionable bug, feature proposal, performance regression, or documentation gap.

## Include This Information

When asking for help, include as much of the following as applies:

- qbtmud version or commit
- qBittorrent version
- browser and operating system
- whether you are using direct alternative WebUI hosting, reverse proxy hosting, or separate API/UI hosting
- exact URL shape, for example whether the app is served from `/`, a subpath, or a different host
- steps taken so far
- screenshots, console output, or server logs if they help explain the problem

## Before Posting a Reverse Proxy or Routing Question

Please include:

- proxy product, such as Nginx, Caddy, or Traefik
- relevant path or host mapping
- whether deep links refresh correctly
- whether qbtmud is using hash routing or path routing in your setup
- whether the qBittorrent API and qbtmud UI share the same origin

## Security Reports

Do not post sensitive security details in a public issue or discussion.

Use GitHub's private vulnerability reporting for the repository if it is enabled. If it is not enabled, contact the maintainer through a private channel before disclosing details publicly.
